# Safelite Promo Code Guide — GitHub Pages site

Static site (no build step). 9 pages, shared style.css / app.js.

## Deploy
1. Create a GitHub repo named `safelite-promo-code-guide` and upload all files in this folder.
2. Repo Settings → Pages → deploy from branch `main`, folder `/ (root)`.
3. Canonical URLs, sitemap and robots already use the live username `safelitecodesguide`.
4. Optional: submit sitemap.xml in Google Search Console for the github.io property.

## Data rule
Code data = checkout tests at safelite.com, last tested October 21, 2026. Never add a code or an expiry date that has not been checkout-tested.
