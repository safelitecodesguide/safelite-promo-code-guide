How to use a Safelite promo code

  1. Pick your code first. Replacement: ADDS100 ($100 off). Repair: SAVENOW2026 ($25 off). Copy it from the code list.
  2. Start a quote at safelite.com — enter your vehicle and ZIP, and choose repair or replacement.
  3. Choose "Pay on my own." This step decides everything: promo codes are not valid on insurance claims, even though the code box still appears on that path.
  4. Open "I have a promo code" on the quote screen and paste the code.
  5. Confirm the discount line. The quote total should drop immediately (for example, $787.63 → $687.63 with ADDS100). If the price doesn't move, the code didn't apply — try the next one.
  6. Book while the discount is showing. One code per order, so keep the single biggest saving.

Troubleshooting

Why was my Safelite promo code rejected?

Either the code has stopped working (five popular codes, including SAVE20SL and AAA10SL, were rejected in testing), it doesn't fit your service, or you're on the insurance path, where codes are not valid. Switch to 'Pay on my own' and try the next tested code.

Can I apply a Safelite code by phone?

Safelite's offers say they are valid when scheduling on safelite.com, and no official page says phone bookings can apply codes. Book online to be safe.

Can I use a code on a mobile (at-home) appointment?

The codes apply to appointments scheduled on safelite.com. In testing they were applied to standard online quotes; check your own quote shows the discount line before confirming.

What if the discount doesn't show?

Don't book and hope. Remove the code, try the next one from the tested list, and only confirm once the price drops on screen.
