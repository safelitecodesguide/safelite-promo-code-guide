Replacement code tips

  • Try codes in size order. One code per order, so start with ADDS100 or LCQ426RCL and work down the list only if one fails.
  • Codes need the "Pay on my own" path. On an insurance claim, the codes are not valid even though the promo box appears.
  • Camera recalibration is part of replacement on many newer cars, and the group code 10THANKYOU10 excludes it — another reason the flat codes usually win.
  • Safelite's own two published codes are the fallback: WEBSL45 ($45) is listed on Safelite's coupons page, and SAFELITEHERORPLC55 ($55) on its hero discount page.
